# Natural ou Fake Natty? Como Vencer na Era das IAs Generativas

## 📒 Descrição
Este projeto consiste no desenvolvimento e refinamento de um **prompt de engenharia (Prompt Engineering)** otimizado para a criação de imagens realistas por meio de Inteligência Artificial. O objetivo principal foi gerar a imagem de uma página de caderno autêntica, contendo uma receita de bolo de chocolate escrita à mão com caneta azul, simulando com precisão os aspectos físicos da escrita humana em papel.

## 🤖 Tecnologias Utilizadas
* **ChatGPT (OpenAI):** Utilizado para a estruturação, tradução técnica e refinamento do prompt em inglês, aplicando técnicas de fotografia macro e texturização.
* *https://www.craiyon.com/*: Utilizada para renderizar a imagem final a partir do prompt estruturado.

## 🧐 Processo de Criação
1. **Concepção da Ideia:** Identificação dos elementos essenciais que tornariam a imagem realista (página de caderno, letra cursiva, tinta azul e o tema de receita de bolo de chocolate).
2. **Engenharia de Prompt:** Tradução e enriquecimento do pedido original para o inglês, adicionando palavras-chave técnicas do vocabulário de fotografia e comportamento de materiais (como *top-down macro photo*, *ink pooling* e *variations in pressure*).
3. **Ajuste de Texturas:** Inclusão de comandos específicos para simular as imperfeições naturais de uma caneta esferográfica real e sombras suaves no papel, garantindo o aspecto analógico desejado.
